# WebSocket engine transport

`createGameServer` wires an engine host to a WebSocket server and durable server persistence. Its default address is loopback and an ephemeral port. The `manual` option disables automatic simulation/publishing for deterministic socket tests. `npm run server` launches it on port 3001; the browser’s local pause menu exposes Servers for connecting.

The server steps at 30 Hz with up to five catch-up frames. A long CPU stall slows simulation rather than accepting client time or rolling back. It offers a current full encoded snapshot every 100 ms, with at most one unacknowledged state per connection. Clients acknowledge after applying a frame; slow clients receive the current world next, without queued intermediate snapshots. Sockets with more than 2 MiB buffered are skipped; paused or application-stalled clients do not receive an accumulating snapshot history. Application heartbeats resume current-state delivery. WebSocket pings detect dead connections.

The initial limits are eight authenticated connections (up to sixteen sockets while authenticating), 64 stored accounts, 4 KiB incoming messages and 120 messages per second per connection. Clients authenticate with their own reconnect token, can enqueue validated intents, pause their own input, and send connection heartbeats. The server never decodes a client-authored snapshot. A receipt acknowledgement means the input reached the mailbox, not that gameplay has executed it.

New account state is persisted before its credential is returned. Interrupted joins remove their unclaimed actor. An authenticated reconnect replaces the old connection for the same account. The old socket loses ownership before closing, so its close callback cannot disconnect the new session. Unauthenticated sockets expire after five seconds. Closing the server releases sockets and writes the current authoritative state. Use WSS on untrusted networks because reconnect tokens are bearer credentials.

Native socket tests exercise two clients, forged actor IDs, queued spell floods, independent pause, wrong credentials, authenticated ownership handoff across process-style restarts and fresh input numbering after a page reload. Gameplay sharing and the current simplifications are described in `src/engine/network/host.md`.
