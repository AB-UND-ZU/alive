# Keyboard/Mouse

Move with the arrow keys or WASD.

[[key:↑]][[key:←]][[key:↓]][[key:→]] Move.

[[key:W]][[key:A]][[key:S]][[key:D]] Move.

[[key:Enter]] Interact.

[[key:Space]] Spell.

[[key:Shift]] Skill/tool

[[key:Q]] Tool / skill.

[[key:B]] View bag.

[[key:E]] Quick actions.

[[key:G]] Gear.

[[key:T]] Stats.

[[key:M]] Map.

[[key:Tab]] Items/tabs.

[[key:Shift]]+[[key:Tab]] Back

[[key:0]] – [[key:9]] Slot.

[[key:Escape]] Close.



Click an on-screen action to use it. Click or tap a dialog row to select it; confirm with its action button.

Nearby objects and equipped items determine the current action.

| Button           | Target                                      |
| ---------------- | ------------------------------------------- |
| [[button:OPEN]]  | Locked door; matching [[item:key]] required |
| [[button:READ]] | [[unit:sign]] |
| [[button:QUEST]] | Character with a quest |
| [[button:SHOP]]  | Trader                                      |
| [[button:CRAFT]] | Workbench                                   |
| [[button:SPELL]] | Equipped spell, such as [[item:wave]] or [[item:beam]] |
| [[button:SKILL]] | Equipped skill or tool, such as [[item:slash]] or [[item:axe]] |

## Dialogs

[[key:↑]] [[key:↓]] Select.

[[key:←]] [[key:→]] Choose.

[[key:Enter]] Confirm.

[[key:Tab]] Change tabs.

[[key:Escape]] Back.

[[key:Backspace]] Left.


## Pause

[[key:Escape]] Pause.

The Pause control also pauses and saves. The pause screen offers [[button:RESUME]], [[button:MENU]] and [[button:SAVE]]. Switching browser tabs also pauses. See [Savegames](savegames.md) for Continue and deleting saves.
