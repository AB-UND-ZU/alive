# Menu

```scene
game/menu
```

Move to a menu item and activate it with [[key:Enter]]. The preview uses the normal game menu.

| Menu item | Description |
| --- | --- |
| Tutorial | Learn the controls in the Dungeon. |
| New Game | Create a character and explore a new Island. |
| Continue | Load a saved game; requires a local save. |
| Sound FX | Toggle game sound effects. |
| Controls | Show the game's keyboard and touch controls. |
| Credits | Show the game credits. |

## Portal map

```widget
level-map-menu
```

The Menu portal leads to the [Dungeon](dungeon.md). See [Portals](portals.md) for the connections between levels.
