# Portals

Travel from the [Menu](menu.md) to the [Dungeon](dungeon.md), then the [Island](island.md). Each level has its own playable preview and map.

```widget
warp-map
```

## Using a portal

```widget
portal
```

Open a portal, select a destination and choose [[button:GO!]]. Green marks an available destination, white the current level and red a locked one. The overview above shows every level in green.

The Island has no onward portal in normal play. Test Mode allows travel between levels.
