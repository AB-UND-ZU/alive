# Dialog Snapshots

Creates an isolated native world, opens its real popup and runs displayPopup at the settled animation time. The resulting native particles supply the tab, frame, text, icons, buttons and scroll markers. No border or dialog text is copied into the wiki renderer.

Use a Markdown widget such as popup buy sell. Snapshots are cached by screen name and do not accept input or write saves. Quest runs the native Earth Chief opening sequence in a small fixture; Sign uses the Dungeon's actual starting sign. Named sign cells select their native text. `forge:add`, `forge:result`, `brew:recipe` and `brew:ingredients` select successive native menu stages using the fixture inventory. `pause` renders the actual Paused React component.

Equipment categories select an actual matching item in the native equipment list. Food selects a usable Bag item. Load builds a sample summary with `createSave` and `getSummary`, then restores the previous in-memory summaries in `finally`; it never writes browser storage.

The message specimen equips an actual Iron Sword through equipItem, then draws the resulting native feedback and hero with worldRows. It reuses the game's equipment message rather than writing a sample response.
