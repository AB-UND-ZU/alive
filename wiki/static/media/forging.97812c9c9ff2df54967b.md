# Forging

```widget
popup forge forge:add forge:result
```

Select carried equipment and an available upgrade. Strike the hot area to complete each step. Each recipe step uses one of ten slots. A miss uses another slot. If a miss would need an eleventh slot, the run ends. Choose Retry to start again with the same recipe and materials.

An exact hit shows Ace! and earns 1 XP. Missing the hot area costs 1 XP, down to zero. A perfect run earns 1 extra XP. Choose Yield to collect the upgrade and release the XP. The upgraded item keeps its equipment slot and quick key. Supported upgrades differ by slot and material.

Material upgrades preserve an existing element. Spirits add an element to plain equipment before its final material tier. The table lists plain bases; the same material costs apply to their elemental variants.
