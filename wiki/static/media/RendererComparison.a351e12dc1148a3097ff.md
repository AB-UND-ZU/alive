# Renderer Comparison

The player-facing comparison uses each renderer's exported capabilities for lighting, shadows, health bars, stack dots and movement. Other rows describe their supported host and controls. Renderer headers link to the corresponding client pages.

The table uses the shared wiki grid layout. It does not change renderer selection or game rules.

The first Example row mounts the same 11-by7 scene in each isolated client at 18-by32 pixel cells. The scene uses real sand, a beach and shallow-to-deep water, mountains, a chest, a four-Apple stack, native visibility and lighting. Frames pause offscreen and have no duplicate HUD or extra instruction. The table keeps its cells wide enough for each frame and scrolls sideways on phones.
