# Levels

Start in the Menu, learn the controls in the Dungeon, then explore the Island.

```widget
warp-map
```

## Portals

```widget
portal
```

Open a portal, select a destination and choose [[button:GO!]]. Green marks an available destination, white the current level and red a locked one. The overview above shows every level in green.

The Island has no onward portal in normal play. Test Mode allows travel between levels.

## Menu

Choose a class and appearance, then enter the Dungeon. Continue opens saved games.

## Dungeon

Open each gate and head north. The pond branches east; the final portal leads to the Island.

```widget
dungeon-map
```

## Island

A mountain range separates jungle and desert. The glacier and ocean wrap around the mainland. Shorelines and settlements change with each new game.
