# Sprite Builder

`openSpriteBuilder` opens a native popup on a separate dialog entity. Its three tabs use the standard tab, selection, scroll and action controls. Edits are saved by [Sprite Pack](../spritePack.md) in localStorage and loaded when the editor opens. Imported assets and game savegames are unchanged. The popup types are `pack`, `sprite` and `layer`, with LIST, VIEW and LAYER tabs. `(New Sprite)` starts a new sprite.

Every tab uses the normal 11-row dialog. The framed image shifts its pixel pairs down half a cell beneath the frame, filling its nine rows without an inner gap. Adjacent half blocks masked by black ║ form two-pixel sides; half-block and line masks close the corners. The wiki preview keeps its fixed scene height.

VIEW keeps the untrimmed 9-by-16 character image on the right while the ordered layer list scrolls on the left. The preview packs two source pixels into each stacked half-block cell and uses the normal character frame. LAYER shares the Welcome atlas character order. COLOR switches vertical movement to the palette; CHAR restores character scrolling. VIEW lists existing layers and one New row. EDIT starts placement mode: its digits blink, Up/Down reorder it, LAYER opens its character editor, and yellow PLACE or Escape finishes placement. Brackets and the large image stay steady during placement. NEW appends a layer after a character is chosen. Color cycling updates an edited layer immediately. BACK keeps edited colors. Opening or leaving LAYER clears placement mode. A new layer is added only after choosing a character. The selected layer blinks in the enlarged image together with its brackets, using the world tick. Its small list character stays visible. Black layers invert the list row content, including its number and brackets. The selection gutter and native arrow stay unchanged. The character grid starts at the left edge. Backspace runs ERASE or DROP; ←BACK and Escape return to VIEW; an unadded new layer is discarded.

Existing LIST entries use the active green arrow and grey dotted lower-half highlight. New entries and browsed layers use the normal arrow and grey dotted lower half. Selected numbers and the New label are white. Inverted black layers keep white backgrounds and black text; their number highlight is grey while browsing and green only while moving, between the white background and text. Layer highlights cover only the two number cells, leaving the brackets and character clear. EDIT activates the green arrow and solid green lower half behind the number while moving a layer. On the New layer row, ←BACK returns to LIST without changing layers.
