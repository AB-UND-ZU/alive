# Dialogs

Nearby characters show speech above their sprites. Transient messages report results without opening a menu. They stay in the current game.

```widget
popup message
```

| Display | Meaning |
| --- | --- |
| Speech | A character's current dialog |
| Transient message | Feedback from an action or command |
| Name and action | Entity name and available interaction |
| Quest marker | Target of the current quest step |

[[key:B]] Open the Bag.

Inspect carried items in the Bag. [Signs](signs.md) open longer instructions; [Quests](quests.md) show tasks and rewards.
