# Keyboard/Mouse

Move with the arrow keys or WASD.

| Input | Action |
| --- | --- |
| [[key:↑]][[key:←]][[key:↓]][[key:→]] | Move in that direction. |
| [[key:W]][[key:A]][[key:S]][[key:D]] | Move in that direction. |
| [[key:Enter]] | Interact with the nearby target. |
| [[key:Space]] | Cast the equipped spell. |
| [[key:Shift]] | Use the selected skill or tool. |
| [[key:Q]] | Switch between Bag tools and skills. |
| [[key:B]] | Open the Bag. |
| [[key:E]] | Open quick item actions. |
| [[key:G]] | Open equipped gear. |
| [[key:T]] | Open character stats. |
| [[key:M]] | Open the Minimap. |
| [[key:Tab]] | Select the next item or tab. |
| [[key:Shift]]+[[key:Tab]] | Select the previous item or tab. |
| [[key:0]] – [[key:9]] | Use the item in that quick slot. |
| [[key:Escape]] | Close a dialog or pause the game. |

Click an on-screen action to use it. Click or tap a dialog row to select it; confirm with its action button.

Nearby objects and equipped items determine the current action.

| Button           | Target                                      |
| ---------------- | ------------------------------------------- |
| [[button:OPEN]]  | Locked door; matching [[item:key]] required |
| [[button:READ]] | [[unit:sign]] |
| [[button:QUEST]] | Character with a quest |
| [[button:SHOP]]  | Trader                                      |
| [[button:CRAFT]] | Workbench                                   |
| [[button:SPELL]] | Equipped spell, such as [[item:wave]] or [[item:beam]] |
| [[button:SKILL]] | Equipped skill or tool, such as [[item:slash]] or [[item:axe]] |

## Dialogs

| Input | Action |
| --- | --- |
| [[key:↑]] [[key:↓]] | Select a dialog row. |
| [[key:←]] [[key:→]] | Change the selected value. |
| [[key:Enter]] | Confirm the selected action. |
| [[key:Tab]] | Switch to the next dialog tab. |
| [[key:Escape]] | Go back or close the dialog. |
| [[key:Backspace]] | Activate the left dialog action. |

## Pause

[[key:Escape]] Pause and save the game.

The Pause control also pauses and saves. The pause screen offers [[button:RESUME]], [[button:MENU]] and [[button:SAVE]]. Switching browser tabs also pauses. See [Savegames](savegames.md) for Continue and deleting saves.
