# Terminal Feature Preview

Composed wiki scenes use this terminal-only chrome. The shared preview entry owns the world and message bridge; this component supplies the terminal text frame and native keyboard input. Normal menu previews load the standalone client instead.

Comparison scenes use the shared `sceneOnly` projection at 11 by 7 cells, with the same 18 by 32 pixel cells as the other renderer examples. Other scenes retain the terminal HUD.
