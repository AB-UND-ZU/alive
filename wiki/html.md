# HTML

The HTML client draws single characters with the game font and layered [sprites](sprites.md) as SVG pixels. It keeps [fog of war](light.md), health bars and item stack dots, without lighting or shadows.

Use `?renderer=html` on the game URL. [Keyboard, mouse](keyboard-mouse.md) and [touch](touch.md) controls match [ThreeJS](threejs.md).
