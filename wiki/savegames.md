# Savegames

```widget
popup pause load
```

[[key:Escape]] Pause and save the game.

Pausing saves the current game in this browser. Use Continue in the main menu to load it.

| Action | Result |
| --- | --- |
| [[button:RESUME]] | Return to play |
| [[button:SAVE]] | Save again without leaving the pause screen |
| [[button:MENU]] | Save and return to the main menu |

Switching browser tabs also pauses and saves. Saving is unavailable in the main menu, during loading and while stepping through a portal.

Each new game gets one save. Saving again replaces it. The name below [[button:SAVE]] is the last save's local date and time: [[data:20261011-151323]] means [[data:11 October 2026 at 15:13:23]].

## Continue

The main menu's Continue portal opens when a save exists. Select a save and confirm [[button:LOAD]]. Play resumes at the saved position, with the saved world, stats and items.

[[key:Enter]] Continue the selected save.

| Save list | Shows |
| --- | --- |
| Order | Most recently saved first |
| Hero | Class, equipped gear and level |
| World | Current level |
| Totals | Deaths, kills and time played |
| Dark red entry | Saved by a newer game version; cannot load |

Older saves upgrade automatically when the save list loads. Your saved world and progress stay intact.

To delete a selected save, choose [[button:ERASE]], then [[button:YES]]. [[button:BACK]] cancels. Erased saves cannot be restored.

Saves stay in this browser on this device. Clearing site data deletes them. The [Play](play.md) page loads preset starting positions and equipment. Pausing saves those games too.
