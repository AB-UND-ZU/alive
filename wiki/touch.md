# Touch

Drag in the terminal to move. The cursor marks where the drag began; its arrows show the held direction. Release to stop.

| Input                | Action                          |
| -------------------- | ------------------------------- |
| Drag outside buttons | Move in the indicated direction |
| Tap action button    | Use its displayed action        |
| Tap a nearby prompt  | Interact                        |
| Tap a menu row       | Select                          |

Tap Pause to pause and save. The pause screen offers [[button:RESUME]], [[button:MENU]] and [[button:SAVE]]. See [Savegames](savegames.md).

## Joystick

The center marks the drag origin. Arrows show the held direction.

```widget
touch-joystick
```

## Try Touch

On a computer, hold the mouse button to drag. Release, leave the preview or switch windows to stop.

```scene
touch
```
