# Gear

```widget
popup gear inspect use equip
```

Gear holds equipped weapons, shields, accessories, spells, skills and tools.

[[key:G]] Open gear.

[[key:B]] View bag.

[[key:E]] Open quick item actions.


[[item:spear]] can thrust through several targets, hitting each limb once. [[item:wand]] casts magic with its action and deals True damage on contact.

```widget
items gear
```
