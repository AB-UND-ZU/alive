# Chat

Chat accepts messages and commands in Test Mode. Messages stay in your game; they are not sent to other players.

```widget
popup chat
```

| Key | Action |
| --- | --- |
| [[key:C]] | Open chat |
| [[key:/]] | Open chat with `/` |
| [[key:Enter]] | Submit |
| [[key:↑]] [[key:↓]] | Previous or next submitted message |
| [[key:Backspace]] | Delete |
| [[key:Escape]] | Close |

## Command Reference

Arguments use spaces and case-sensitive names. `<arg>` is required; `[arg]` is optional. Invalid arguments return an error or usage above the hero.

```widget
command-reference
```

## Command Builder

Run a command here. Search finds item names; Tab accepts the gray completion. Arrow keys select a suggestion. Commands share the same isolated world, so pins and stat changes remain available to later commands.

```widget
commands
```
