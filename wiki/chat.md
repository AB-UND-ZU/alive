# Chat

Messages appear above your character for [[data:3]] seconds. A new message replaces the previous one. On servers, nearby players can read them.

Commands require Test Mode in single player or server admin permission in multiplayer.

```widget
popup chat
```

[[key:C]] Open chat.

[[key:/]] Enter a chat command.

[[key:Enter]] Send the chat message.

New messages replace the previous message. After three seconds, it untypes and disappears.

[[key:Tab]] Complete the command.

[[key:↑]] [[key:↓]] Browse command history.

[[key:Backspace]] Erase the last character.

[[key:Escape]] Clear the chat input.


## Command Reference

Arguments use spaces. Item names are case-sensitive; server usernames are not. `<arg>` is required; `[arg]` is optional. Invalid arguments return an error or usage above the hero.

```widget
command-reference
```

## Try Commands

Type `/gi`. Tab accepts the gray suggestion; on touch screens, swipe right over the dialog or keyboard. Type a longer prefix to narrow the suggested word. Up and Down choose a suggestion. From an empty line, Up recalls messages saved in this browser.

```scene
chat
```
