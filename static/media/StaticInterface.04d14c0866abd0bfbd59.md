# Static Interface

Mounts the real `World`, `Stats`, `Terminal`, `Controls` and camera with the Island start fixture. The native renderer and systems run normally; pointer and keyboard focus are disabled. The fixture viewpoint keeps the hero centered. Saving is disabled for this reference.

The labelled and reference views use the same components and world setup. The reference hash omits annotations for visual comparison. Labels overlay the terminal without replacing any game controls or cells.
