## Content and behavior

- Chat has three useful areas: the native chat and key actions, a complete command reference from `commandSignatures`, and the command builder. `/gi` followed by Tab becomes `/give ` on both screen sizes. Running `/stat hp 12` changes the actual isolated world's HP to 12; the native successful-set result is shown as Done. Searching sword returns its real sprite and name. The builder keeps its world between commands.
- Dialogs explains speech, transient feedback, entity interactions and quest markers. Its native `hp = 25` example demonstrates transient feedback. The final revisit confirms B opens the Bag to inspect carried items; it no longer claims that B opens a general entity-inspection mode.
- Signs starts with READ, then shows the native sign examples and their key actions. The phone revisit checks the gallery's start, middle and end before the key table. READ and the Bag behavior match current Controls/interaction source.
- Savegames starts with the actual Pause and populated Load displays, followed by save actions, storage ownership, timestamp format, Continue details and deletion. The displayed sample date matches the documented format. The information has a clear order and each paragraph describes a concrete behavior.
- Quests starts with the native Chief/CLAIM display, explains interaction, then separates Dungeon, Earth Town, Fire Haven, Nomad and belongings. Stages, requested alternatives, rewards, named characters and feature links convey useful information. Source spot checks confirm the Chief's free Iron Compass, three Golem heads for the Fire Chief's Gold/10 XP/Wood Pickaxe, and the Nomad's alternatives of 16 Berry/Flower/Spore. Sprite references and counts are visible in the tables.

All visits completed without runtime errors. Checked pages retain their viewport widths; wide phone tables and native media scroll locally. No source changes were made during this review. The Signs and Bag wording corrections were made by their source owner and were verified in the final served pages.
