# DISPLACABLE

Allows movement caused by pushing or sliding.

Attach with `world.addComponentToEntity(entity, DISPLACABLE, data)`. Query with `world.getEntities([DISPLACABLE])`.

Systems: `freeze`, `magic`, `push`.
