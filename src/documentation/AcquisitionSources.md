# Source Groups

Every acquisition kind uses a compact native frame. Each line stays intact; a frame measures its title and longest content line. Drop has one frame containing every producing entity, without probability subgroups or enemy summaries. An invisible Rotten unit is represented by its actual fallen-tree cell.

Shops uses native Buy and Sell prices on separate lines. Levels uses the green world-map sprite, level name and known biome. Fishing lists every supported level and its native catch chance. Crafting, forging and brewing each use one frame per recipe option, with one counted ingredient per line. Natural pickups and harvest targets reuse `CellReference` and `HarvestTarget`; quests use native NPC references. Missing source data stays empty.
