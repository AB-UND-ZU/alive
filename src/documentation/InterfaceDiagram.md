# Interface Diagram

Embeds the noninteractive native interface with its Island start area and centered hero. HUD, controls, camera, entity layers, equipment and backdrops are the actual game components, rather than manually drawn substitutes.

The iframe URL resolves against the application's captured documentation base, so navigation between nested routes does not change its asset path. The iframe isolates game dimensions and styles. Its annotations are noninteractive and stay in the terminal's cell grid.
