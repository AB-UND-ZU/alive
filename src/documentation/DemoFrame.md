# Demo Frame

Draws a character-cell boundary over the game terminal. Feature scenes use a stationary viewpoint that yields to open dialogs at `(6, 4)` and hidden collision walls at `x = -4 / 16`, `y = -2 / 10`. The frame occupies those same cells. Focus changes its color from silver to green. The action row starts half a cell below the frame line.

The Interface illustration uses the full terminal frame around the imported Island spawn area.
