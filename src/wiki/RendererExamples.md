# Renderer Examples

A compact sprite comparison uses the same Rogue, tree, chest, ground and water in each column. ThreeJS and HTML share the game's layered sprite data. The terminal column calls `projectSprite` and renders its character and foreground/background colors using the shared wiki cells.

These are static sprite examples; lighting and camera behavior are shown by the live previews on the client pages. No extra game world is created for this table.
