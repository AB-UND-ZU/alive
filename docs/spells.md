# Spells

[[key:Space]] casts the equipped spell. Each cast requires mana.

[Elements](elements.md) change spell and equipment effects.

A cast can hit several targets. Each target is affected once per cast. Friendly relationships and immunity can prevent an effect.

```widget
items spells
```

## Direct Casts

Bolt and blast are effects used by `/cast`, not equippable spell items.

```text
/cast bolt iron fire
/cast blast iron water
```
