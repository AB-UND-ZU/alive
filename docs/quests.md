# Quests

Interact with a sign or character to start a quest. Follow its marker and complete the current task.

| State | Behavior |
| --- | --- |
| Start | A sign, NPC or portal starts a quest sequence |
| Step | The quest waits for its condition or interaction |
| Highlight | A marker identifies the current target |
| Complete | The sequence advances or ends |

The tutorial guides movement, keys, doors and conversations. Island quests use the same sequence system.
