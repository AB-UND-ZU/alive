# Touch

Drag in the terminal to move. The Stats and Controls bars keep their touch targets outside that area.

| Input                | Action                   |
| -------------------- | ------------------------ |
| Drag outside buttons | Move                     |
| Tap action button    | Use its displayed action |
| Tap a nearby prompt  | Interact                 |
| Tap a menu row       | Select                   |

Tap Pause to pause and save. The pause screen offers [[button:RESUME]], [[button:MENU]] and [[button:SAVE]]. See [Savegames](savegames.md).
