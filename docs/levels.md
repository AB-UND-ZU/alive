# Levels

Start in the menu, learn the controls in the Dungeon, then explore the generated Island.

| Level   | Layout                                            |
| ------- | ------------------------------------------------- |
| Menu    | Tutorial sign, new game, Continue, sound, credits |
| Dungeon | Fixed tutorial rooms, keys, quests, combat        |
| Island  | Generated terrain, towns, resources, encounters   |

```text
 Menu ──► Dungeon ──► Island
```
