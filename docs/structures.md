# Structures

Open a door and enter to see the interior. Locked doors consume a matching [[item:key]] once. Roofs hide the interior while outside; entering reveals the rooms and hides the surrounding world.

```widget
structure-overview
```

```widget
units structures
```

Use [Building](building.md) to place structures with [[item:hammer]].

The preview starts at a locked house. Unlock the door, then move through it to reveal the interior.

```scene
structures
```
