# Tips

Tooltips name nearby objects and show available actions. Inspect with [[key:B]] or point at a cell.

| Prompt            | Meaning                                      |
| ----------------- | -------------------------------------------- |
| Name above a unit | Inspection tooltip                           |
| Action label      | Available interaction for the current target |
| Quest highlight   | Target selected by the current quest step    |
| Timed message     | Dialog or tutorial feedback                  |

Signs and NPCs can provide instructions through their dialog or quest.
