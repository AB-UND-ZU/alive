# Terrain

Ground changes movement and what can be built or harvested. Deep water blocks walking away from shore.

| Ground        | Effect                                            |
| ------------- | ------------------------------------------------- |
| Path          | Faster movement                                   |
| Sand          | Slower movement                                   |
| Shallow water | Wade near land; slowed; extinguishes fire         |
| Deep water    | Blocks walking away from shore; cross with a boat |
| Ice           | Slide until leaving ice or hitting an obstacle    |
| Mountain      | Blocks movement and sight                         |
