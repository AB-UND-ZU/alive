# Respawn

At zero HP, the hero dies and drops unbound items. Respawn and return to the grave to recover them.

```text
 HP = 0 ──► Grave + dropped unbound items
                   │
                Respawn
                   │
            Return to spawn
                   │
         Follow marker to grave
```

Dropped items occupy nearby free cells. Current mana and XP are not restored by collecting belongings. Pausing saves the current world. See [Savegames](savegames.md).
