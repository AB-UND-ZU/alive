# Tools

```widget
popup equip:tool
```

Equip a tool and choose a direction when prompted.

| Key | Action |
| --- | --- |
| [[key:Shift]] | Activate the equipped tool |
| [[key:Q]] | Switch between tool and skill |

```widget
items tools
```

[Harvesting](harvesting.md) lists tool targets and yields. [Fishing](fishing.md) covers bait and catches; [Building](building.md) covers [[item:hammer]] plans.
