# Consumables

Use food and potions to restore stats. Open the item menu with [[key:E]], select an item and confirm.

Percentage effects use the maximum stat. [[item:thorn]] hurts when consumed.

## Potions

Potions activate automatically below a threshold. Each dose has a cooldown. A small gap below maximum leaves room for loose health and mana drops.

items consumables
